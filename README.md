# tronya.github.io

Landing: projects (`/`) and the games catalogue (`/games/`). The list lives in `assets/projects.js`.

Games live in their own repositories with GitHub Pages enabled and are served at
`tronya.github.io/<repo-name>/` (e.g. `mars-rover` → `/mars-rover/`).

Locally: `python3 -m http.server 5180` and open http://localhost:5180/
