# Solar Rover

Симулятор сонячного ровера на Марсі. Three.js, без збірки й без залежностей —
відкриваєш `index.html` і граєш.

Перехід від бази **АЛЬФА** до бази **БЕТА**. Рівна дорога петляє схожою на літеру S лінією
і має близько 10 км. Навпростець удвічі ближче, але через горби, кратери й валуни. Вдень розкладаєш
сонячні крила й заряджаєшся, вночі їдеш на батареях.

## Як запустити

Потрібен будь-який статичний сервер (модулі ES не працюють з `file://`):

```bash
python3 serve.py 5173
```

Далі відкрий <http://localhost:5173/>.

## Керування

| Клавіші | Дія |
| --- | --- |
| `W` / `S` | газ / гальмо, далі задній хід |
| `A` / `D` | кермо — відпусти, щоб повернути прямо |
| `Пробіл` | ручне гальмо |
| `Shift` | турбо, витрачає батарею вчетверо швидше |
| `E` | сонячні крила |
| `L` | світло: авто / вимк / габарити / фари |
| `R` / `H` | поставити на колеса / повернутись на базу |
| `P` | автопілот |
| `M` | 3D-карта |
| `O` | меню, налаштування звуку й список клавіш |
| `K` | звук |

Карта внизу зліва — маленький рельєф усього переходу, що повільно обертається
сам собою. Клац по ній відкриває велике діалогове вікно: там можна обертати
камеру мишею (перетягування — орбіта, колесо — зум) і кожен короткий клац по
землі ставить точку маршруту. Автопілот їде лише через точки, які ти поставив;
без жодної точки він просто стоїть, а не їде до бази сам. Коли батарея сідає,
він зупиняється, розкладає крила, чекає до повного заряду, складає їх і їде
далі. Хрестик у кутку карти згортає її назад у маленьку.

Стрічка вгорі по центру — компас: показує напрямок руху й сторони світу.

## Що всередині

| Файл | Призначення |
| --- | --- |
| `src/physics.js` | тверде тіло, підвіска, шини, зчеплення |
| `src/vehicle.js` | модель ровера, колеса, сонячні крила |
| `src/terrain.js` | рельєф, S-подібна дорога, потокова генерація тайлів |
| `src/tracks.js` | колія від коліс |
| `src/base.js` | база з маяком |
| `src/sky.js` | небо, цикл дня й ночі |
| `src/audio.js` | синтезований звук, без аудіофайлів |
| `src/minimap3d.js` | окрема 3D-сцена рельєфної карти |
| `src/main.js` | сцена, керування, живлення, HUD |

Фізика рахується в СІ з марсіанською гравітацією 3.71 м/с². Рельєф заданий
функцією, а видима частина підвантажується тайлами навколо ровера, тому світ у
10 км працює без підвисань.
